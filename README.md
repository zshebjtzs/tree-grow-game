# 🌳 生长树：图论 (Growth Tree: Graph Theory)

这是一款基于**图论（有向树）**与**拓扑地图**的离线双人热座策略游戏。玩家在由 Voronoi 多边形构成的随机地图上，通过生长“树木”来扩张领土、摧毁敌方根系，并突入敌方基地。

> 💡 **开发灵感**：基于 B站 UP主“浩辰-_”的原创纸上游戏《生长树》改编。在原版基础上，我们为游戏引入了严格的“有向树”图论数学模型，并扩展了地形战略深度。

---

## 🎮 玩法介绍

游戏开始前，红蓝双方玩家将依次在随机生成的**多边形地图**上选择自己的初始基地。基地选址完成后，每个基地内会自动生成 **3 个根节点**。玩家轮流操作，在自己的回合内，必须从一个已有的节点出发，穿过一条边界线，在**相邻的空区域**落下一个新的叶节点，从而完成一次生长。

你要做的，就是用你的树枝连成网络，去封锁敌方的去路，或者直接砍断敌方连接到根的枝条，占领敌方老巢！

## 📜 核心规则

基于图论的**有向树**数学模型，游戏拥有严谨且反直觉的摧毁与防御机制。

### 1. 基础定义
*   **根节点**：基地内的起始点（每个玩家 3 个）。
*   **叶节点**：树木的末端终点。
*   **分支点**：连接了 **≥3条** 树枝的节点。
*   **边界线**：划分不同多边形的黑线。

### 2. 生长规则
*   **绝对限制**：每回合玩家必须**同时**画出一条新的树枝，并在端点落下一个新的叶节点。**节点与节点之间不可直接连接**。
*   **跨区限制**：
    *   **初生限制**：从根节点伸出的**第一条树枝**，最多只能跨越 **2 块**己方已占据的区域。
    *   **后续限制**：根节点长出第一根树枝后，所有后续的新树枝**只能穿过一条黑线进入相邻的 1 个区域**，且**绝对不可跨越任何已被占据的区域**（无论是己方还是敌方的）。

### 3. 战斗与摧毁机制
当玩家新长出的叶节点，落入了敌方节点所在的**同一区域**时，触发战斗。战斗根据敌方节点结构自动判罚：

*   **连锁摧毁（削枝）**：
    如果侵入的是敌方边缘的**叶子或单链节点**，系统会顺着这条单链向上回溯，一直寻找**最近的一个分支点**。该分支点**安全保留**，但属于该分支点以下的**整条枝干被彻底砍断**。
*   **直接摧毁（断根）**：
    如果侵入的是敌方一个连接数 **≤3条** 的分支点（即脆弱节点），系统会**连根拔起该分支点及其下辖的所有分支**，直到上一级分支点。
*   **终极摧毁（斩首）**：
    如果被摧毁的是一根**没有任何分支、单线直通根节点**的树枝，那么这根树枝连同它的**根节点一同毁灭**。

### 4. 防御堡垒机制
当玩家培育出了一个连接 **>3条树枝** 的分支点时，它将成为一座**绝对防御堡垒**。
*   **无法被摧毁**：它免疫上面的“直接摧毁”规则。
*   **不可进入**：敌方树枝**无法踏入**这座堡垒所在的区域。

### 5. 胜利条件
达成以下**任意一项**条件即可获胜：
1.  **战略突入**：己方的新树枝成功进入**敌方基地所在区域**。
2.  **彻底覆灭**：将敌方所有的 **3 个根节点**全部摧毁。

## 💡 进阶策略提示
1.  **连点成线，步步为营**：由于“不能连穿两条线”，你的树木需要沿着地图的地形一点点蔓延。
2.  **保护“分叉点”**：分叉点是树木的命脉。尽量将分叉点建立在防御堡垒内，或确保连接它的路径有足够多的退路。
3.  **小心“接壤”**：如果发现敌方树枝已经和你的树枝接壤，务必算好谁先谁后，利用规则实现一次漂亮的“换子”。
4.  **诱导佯攻**：故意让对手砍掉一根不重要的单链，以此保护己方核心基地的安全。

## 🛠️ 技术栈与实现
本项目目前是一套**纯前端**的单机网页应用，方便直接运行测试。

*   **核心语言**：原生 `HTML5` + `CSS` + `JavaScript (ES6 Module)`。
*   **渲染引擎**：`HTML5 Canvas`（所有多边形、连线、节点皆由 Canvas 原生 API 绘制，性能极高）。
*   **地图生成算法**：引入了第三方轻量库 **`d3-delaunay`**，通过**沃罗诺伊图（Voronoi Diagram）**算法生成随机且具备严谨图论结构的封闭多边形地图。
*   **存档机制**：利用浏览器的 `File System Access API`。玩家点击保存会直接弹出系统的“另存为”窗口，生成一个独立的 `*.sav` 单文件，真正做到了像单机游戏一样本地存储。

## 💻 如何本地运行与开发
这是一个纯静态 Web 项目，**无需安装 Node.js 或配置环境**。

1.  将代码 `git clone` 到本地。
2.  使用 **VS Code** 打开项目。
3.  在 VS Code 插件市场中安装 **`Live Server`** 插件。
4.  在 `index.html` 上右键，选择 **"Open with Live Server"**。
5.  游戏将在浏览器中自动打开，你可以立刻与好友在同一设备上进行本地双人对战。
